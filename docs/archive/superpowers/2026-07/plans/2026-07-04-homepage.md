> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement a responsive, feature-rich forum homepage using SF components, i18n locales, mock data, and visual styling.

**Architecture:** Update index.vue with a responsive 3-column grid layout binding custom SF component library elements to standard reactive forum states. Update zh-CN and en-US localization bundles with homepage copy. Write a validation script to verify structure and locales.

**Tech Stack:** Nuxt 4, Vue 3, Vue I18n, Tailwind CSS, TypeScript.
