# 首次注册与超级管理员

[← 使用说明](./README.md)

## 身份模型

SForum **只有一套用户系统**：普通会员、版主、管理员都是同一 `users` 体系下的角色与权限差异。

| 角色 | 说明 |
| --- | --- |
| **第一个注册用户** | 自动成为受保护的 `super_admin` |
| **`member`** | 开放注册后的默认角色；角色键稳定，展示名可改 |
| 其他内置角色 | 如版主/运营等模板（见后台角色管理） |

## 首次启动后建议步骤

1. 用浏览器打开站点（开发默认 <http://127.0.0.1:3000>）。  
2. 完成**第一个**账号注册（用户名、邮箱、密码）。  
3. 登录后访问管理后台：`/control-panel`。  
4. 在 **站点设置 / 个性化** 中确认站点名称、语言、外观。  
5. 配置邮件（内置 SMTP 插件）以便密码重置与通知可用。  
6. 创建版块与标签，再开放邀请他人注册（或按策略关闭注册）。

## 超级管理员保护

初始 `super_admin`：

- 不可删除、不可禁用、不可剥夺超级管理员权限（产品硬边界）  
- 后续可通过角色与权限矩阵授予其他管理员能力，但高危操作仍应最小化授权

## 会话与安全

- 浏览器会话由服务端 Redis 会话支撑（非「仅 JWT 当唯一真相」）  
- 账户安全页可管理登录设备、撤销会话  
- 生产环境务必修改 `.env.production` 中的密钥与数据库密码  

## 人机验证（ALTCHA）

- 注册等场景可启用 ALTCHA  
- 开发默认常为关闭，避免本地联调摩擦  
- 在后台「验证 / 安全」相关设置中按场景开关
