# 短代码（Built-in Shortcodes）

[← 使用说明](./README.md)

短代码是主题/评论正文中可以嵌入的结构化引用与受保护内容块，由随发行版内置的
受保护插件 **`sforum-shortcodes`** 提供。服务端把它们转换为规范化文档节点，
再按当前查看者组合安全输出；任何一段短代码写法都**不是**可执行的存贮 HTML。

## 支持列表（8 种）

| 短代码 | 规范语法 | 作用 | 限制 |
| --- | --- | --- | --- |
| 用户引用 `user` | `[user user_id="42"][/user]` | 渲染公开用户摘要卡片 | 参数 `user_id` 必须为正整数；引用节点无正文 |
| 主题引用 `topic` | `[topic topic_id="123"][/topic]` | 渲染公开主题预览 | `topic_id` 正整数；已隐藏/删除/待审等非公开目标不渲染，显示“未找到”样式（不含目标元数据） |
| 评论引用 `comment` | `[comment comment_id="456"][/comment]` | 渲染公开评论预览，仅当评论与其所属主题都公开 | `comment_id` 正整数；评论隐藏或所属主题非公开时不渲染 |
| 分类引用 `category` | `[category category_id="7"][/category]` | 渲染公开分类卡片 | `category_id` 正整数 |
| 友情链接 `friend-links` | `[friend-links][/friend-links]` | 按运营配置顺序渲染已启用的友链 | 无参数；没有已启用友链时不输出任何内容 |
| 登录可见 `login` | `[login]内容[/login]` | 仅当前有效登录用户可见 | 必须包含正文；上下文必须是完整块 |
| 回复可见 `reply` | `[reply]内容[/reply]` | 主题作者，或在同一主题有至少一条当前公开已接受评论的用户可见 | 必须包含正文 |
| 仅作者可见 `only-author` | `[only-author]内容[/only-author]` | **仅评论**；评论作者或该主题作者可见 | 放在主题中不转换；必须包含正文 |

### 语法规则

- 短代码标签必须独占一行（缩进不超过 3 个空格）；与前后文字同行时不转换。
- 引用节点（`user`/`topic`/`comment`/`category`/`friend-links`）必须有成对闭合标签
  `[/name]`，且不允许正文。
- 受保护块（`login`/`reply`/`only-author`）也必须有成对闭合标签，正文内可包含
  普通 Markdown 块内容（段落、标题、列表、引用、代码、图片、其他短代码），
  嵌套最多 4 层，整篇最多 32 个短代码节点。
- 参数规范写法为 `key="value"`；导入/粘贴时也接受未加引号的正整数
  （如 `user_id=42`），会自动规范化为带引号形式；前导零会被去除。
- `user_id`/`topic_id`/`comment_id`/`category_id`/`tag_id` 必须映射到正确的
  参数名；其他参数名、`0`、负数、非数字、超过 int64 的值都**不转换**，保持原文。
- 转义写法 `\[user ...]`、行内代码、缩进/围栏代码块、原始 HTML 块、表格内
  的短代码文本一律不解析（代码内容是“不透明”的）。
- 未知或不支持的旧标签（如旧版 `media`/`chart`/`alert-*`/`carousel`/
  `button`/`file`/`InvitationCode` 等）保持原文显示。

### 编辑器快捷方式

- 工具栏短代码入口（`引用`动作）：搜索并插入 `user`/`topic`/`comment`/
  `category`；`friend-links` 直接插入；选中正文后可包裹为 `login`/`reply`/
  `only-author`（评论域）。
- 粘贴或输入规范语法时会自动转换为对应节点；受保护块可以改类型、删除或
  解包；整个流程不需要手写语法，也没有源码模式。

## 旧版兼容

### `topic-tag` 只是 `category` 的导入别名

旧版 SForum 的板块引用写作
`[topic-tag tag_id="7"][/topic-tag]`。现在粘贴/导入它只会转换为**当前
`category` 引用**：

```text
[topic-tag tag_id="7"][/topic-tag]   →   [category category_id="7"][/category]
```

- 它**不会**转换为旧的“标签引用”节点，也不会以 `topic-tag` 身份存入内容、
  导出或搜索文本。
- 新内容请直接使用 `[category category_id="7"][/category]`。

### `friend_links` 旧名字不自动转换

旧版写作 `[friend_links]`（下划线，且有时没有闭合标签）。下划线拼写**不是**
别名：它会保持原文，不会渲染友链。请手动改为规范的
`[friend-links][/friend-links]`。

### `password` 暂不支持（deferred）

旧版的 `[password password="..."]…[/password]` 密码可见内容**不在** V1
范围内，也**不会**有任何转换或密码/凭据行为。该语法保持原文字面显示，
不会被解析、不会出现输入框、不会校验密码。它需要独立的凭据、限流、
访问会话、恢复、审计与密钥生命周期设计，本阶段明确不实现。

## 保护内容（`login` / `reply` / `only-author`）

| 场景 | 看到的内容 |
| --- | --- |
| 匿名用户 | “登录后可查看此内容”（`login`）/“回复后可查看此内容”（`reply`）/ 仅作者可见提示（`only-author`）；正文任何情况下都不出现 |
| 登录但未满足条件 | 同上对应提示；正文不出现 |
| 满足条件（`login` 有效会话；`reply` 主题作者或同主题有当前公开已接受评论；`only-author` 评论作者或主题作者） | 服务端组合出的受保护正文 |
| 版主/管理员在公开页面 | **没有**隐式放行；公开页面按同一策略判定。后台审核/修订界面属于受保护的管理员查看路径 |
| 插件禁用 / Safe Mode / 运行时不可用、超时、崩溃、输出非法 | “受保护内容暂不可用”提示；正文保持隐藏 |
| 作者重新编辑 | 通过权威的编辑源接口恢复规范节点（见下），公开 JSON 中始终没有原始源码 |

受保护子内容在写入时就已从公共 HTML、纯文本、摘要、搜索文本、SEO 中排除，
并且在服务端按查看者组合——不是靠 CSS 隐藏，不是客户端判断，更不会出现在
Nuxt 页面数据、SSR 原始 HTML 或任何共享缓存里。

### 公开正文、搜索、SEO 与摘要

- 受保护正文**不会**进入：公开主题/评论接口、SSR HTML、Nuxt payload、
  纯文本、摘要、站点/第三方搜索索引、SEO/OG/JSON-LD、sitemap。
- 存贮的公共占位符使用**站点默认语言**；若运营者修改站点默认语言，需要
  触发内容重新渲染与搜索重建。
- 引用卡片不会把解析后的用户名/主题标题/ID 写入搜索文本，搜索文本只有
  稳定的默认语言标签。
- 个性化输出（对满足条件的查看者）不会被共享缓存：携带受保护内容的
  响应为 `private, no-store`。共享缓存只保存与查看者无关的公共基础数据。
- 主题/评论的 observe 事件与 Webhook 不包含正文或受保护字段；受保护子内容
  不会触发 @提及通知、链接预览或外链投影。

## 编辑、预览与重新编辑

1. **编辑**：在编辑器中直接编辑受保护块内部内容；引用节点通过对话框选择
   目标后生成，也可直接粘贴规范语法。
2. **预览**：编辑器写入模式中受保护块以带边框的节点呈现，可编辑其内部内容；
   但客户端只会把它序列化为“受保护内容暂不可用”占位，**不会**把受保护正文
   写入预览 HTML、复制导出的 Markdown/HTML 之外的任何公开客户端视图。
3. **发布**：保存后由服务端重新校验、规范化并按当前查看者组合输出。
4. **重新编辑**：编辑器通过权限校验的 `/topics/{id}/edit-source`、
   `/comments/{id}/edit-source` 恢复当前规范源；公开接口不返回原始源码，
   请不要从公共 JSON/Nuxt payload 中“抢救”源码。

## 运营说明

### 启用、禁用与回退

- `sforum-shortcodes` 是随发行版内置的受保护插件。API 启动时 `SyncBuiltins`
  会以精确制品暂存它；是否启用由管理员在「扩展 → 插件」中正常确认。
- **启用后**：8 个短代码声明进入 Content Registry，短代码开始转换/渲染。
- **禁用 / Safe Mode / 制品缺失或运行时不可用时**：声明被移除，短代码
  **不会转换**为节点；用户文本按上文“保持原文”或 Host 占位回退处理，普通
  内容不受影响，受保护正文依旧隐藏。
- 该插件目前**没有运营设置项**：没有开关、没有参数、没有恢复默认按钮。
  “恢复推荐配置”= 在扩展管理中确认它为启用的精确制品；任何“回到不转换”
  的预期都是禁用插件或使用 Safe Mode。

### 失败回退矩阵（公开页面）

| 短代码 | 运行时不可用/禁用 | 目标非公开/无权 | 输出非法 |
| --- | --- | --- | --- |
| `user` | 用户引用暂不可用 | 通用不可用标签 | 通用不可用标签 |
| `topic` | 主题引用暂不可用 | “未找到”样式（无目标元数据） | 通用不可用标签 |
| `comment` | 评论引用暂不可用 | “未找到”样式（无目标元数据） | 通用不可用标签 |
| `category` | 分类引用暂不可用 | 通用不可用标签 | 通用不可用标签 |
| `friend-links` | 无输出（仅 trace 原因） | 不适用 | 无输出 + trace 原因 |
| `login` | 受保护内容暂不可用；正文隐藏 | 登录后可查看此内容；正文隐藏 | 正文隐藏 |
| `reply` | 受保护内容暂不可用；正文隐藏 | 回复后可查看此内容；正文隐藏 | 正文隐藏 |
| `only-author` | 受保护内容暂不可用；正文隐藏 | 此内容仅限相关作者查看；正文隐藏 | 正文隐藏 |

提示文案使用请求语言；存贮的公共占位符使用站点默认语言。

### 搜索、缓存、日志与事件排除规则

- 搜索：受保护子内容与解析后的引用标题/ID 都不进入索引。
- 缓存：共享缓存只包含与查看者无关的公共基础数据；个性化输出
  `private, no-store`。
- 日志/trace：只记录有界标识、版本、结果/回退原因码、耗时与聚合计数，
  不记录参数、子正文、序列化文档、渲染输出、actor 身份、原始错误或缓存值。
- 事件/Webhook：不新增正文或受保护字段；受保护子内容不触发提及、链接预览
  与外链投影。
