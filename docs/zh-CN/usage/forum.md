# 论坛日常

[← 使用说明](./README.md)

## 内容模型（运营需知）

| 概念 | 含义 |
| --- | --- |
| **Topic（主题）** | 用户看到的帖子/话题 |
| **Comment（评论）** | 主题下的树形回复 |
| **Post（内容行）** | 底层共享正文存储（含修订）；一般不对访客暴露该词 |
| **Category / Tag** | 版块与标签；标签支持 Unicode slug |

## 站长配置清单

1. **版块与标签**：后台维护分类树与标签；可配置图标与颜色。  
2. **论坛策略**：发帖长度、评论嵌套深度、编辑时间窗、冷却与日限额、访客是否可读等。  
3. **访客阅读**：关闭访客读时，未登录用户无法浏览受保护列表/详情。  
4. **版主能力**：锁定、置顶、隐藏/恢复等（需对应权限）。  
5. **审核**：可配置预发布审核与用户举报工作流。  

限制对前台编辑器与 API 同时生效（服务端权威）。

## 内容编辑与版本历史

- 作者编辑仍受站点编辑窗口限制；持有 `topic.edit_any` 或 `post.edit_any`
  的工作人员可在后台处理相应内容。每次有效保存都会形成一个新的已接受版本。
- 后台「论坛管理 → 内容管理」按主题或回复浏览所有生命周期状态。版本时间线仅向
  `topic.revision.view_any` 或 `post.revision.view_any` 的工作人员开放，列表不会泄露原始正文。
- 恢复需要对应的历史查看权限和 `*_edit_any`，且必须填写原因。恢复会创建新版本，
  不会改写旧版本，也不会改变审核或生命周期状态。
- 两个编辑者同时保存时，旧版本令牌会收到冲突；请重新加载最新内容或查看历史后再编辑。
  V1 没有强制覆盖。
- 仅 `super_admin` 能永久脱敏非当前版本，需输入原因和 `REDACT` 确认。脱敏后只保留
  版本头，正文、预览和恢复均不可用。

## 会员常见操作

- 浏览首页信息流、版块、标签页  
- 发帖 / 回帖 / 编辑（在策略允许的时间窗内）  
- 个人资料与账号设置（含头像策略、会话管理）  
- 举报不当内容
