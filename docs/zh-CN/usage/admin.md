# 管理后台

[← 使用说明](./README.md)

## 入口

- 默认路径前缀：`/control-panel`  
- 环境变量：`NUXT_PUBLIC_ADMIN_ROUTE_PREFIX`  
- 也可在运行时站点选项中配置（以当前版本后台「站点设置」为准）

无足够权限的用户无法完成管理 API 调用；前端隐藏菜单只是体验层。

## 界面习惯

| 能力 | 说明 |
| --- | --- |
| 多标签页 | 后台多页签浏览，避免丢上下文 |
| 模块注册表 | 侧栏/页面元数据由注册表驱动，扩展可声明后台入口 |
| 推荐默认 + 恢复 | 可配置项应提供推荐值与一键恢复；恢复若保留密钥会在 UI 说明 |
| Toast | 保存、重置、上传等操作应有成功反馈；错误 Toast 不自动关闭 |

## 常见管理区域

具体菜单文案随版本与扩展变化，典型包括：

| 区域 | 用途 |
| --- | --- |
| 概览 / 运维 | 健康、队列、调度任务 |
| 站点 / 个性化 | 名称、品牌、导航、页脚、公告、外观主题色 |
| 论坛设置 | 主题/评论长度、嵌套、冷却、访客阅读、标签策略等 |
| 内容管理 | 按主题/回复筛选、编辑、查看受限版本时间线、对历史版本恢复；恢复必须填写原因 |
| 分类与标签 | 版块树、标签、图标颜色 |
| 用户 / 角色 / 权限 | 成员管理、角色模板、权限矩阵、用户级覆盖 |
| 附件 | 存储提供方、治理、孤儿清理策略 |
| 邮件 | 邮件提供方选择、测试邮件、邮件投递历史 |
| 通知 | 类型/渠道策略、Web Push 提供方、管理员自测与脱敏投递健康 |
| 版务 / 审核 | 举报、预审、工作台 |
| SEO | 元数据、robots/sitemap 相关 |
| 扩展 | 插件列表、主题激活、设置、事件日志、信任 |

## 权限提示

- 新增后台能力时，权限键应可授予，而不是写死「只有超级管理员」除非安全必需  
- 插件可**声明**权限键，但安装/启用**不得**自行赋权；授权始终由宿主角色管理完成  

## 内容版本权限

- `topic.revision.view_any` 与 `post.revision.view_any` 仅允许查看对应历史；它们本身不授予编辑。
- 恢复还需要相同资源的 `topic.edit_any` 或 `post.edit_any`。冲突状态只能重新加载或查看历史，
  没有强制覆盖操作。
- 脱敏历史版本是不可逆的 `super_admin` 操作，当前版本不可脱敏。历史原始正文、恢复原因和
  附件提供方细节不会进入扩展事件或普通审计日志。
