# 管理后台

[← 使用说明](./README.md)

## 入口

- 默认路径前缀：`/control-panel`
- 环境变量：`NUXT_PUBLIC_ADMIN_ROUTE_PREFIX`（当前只能通过环境变量配置）

无足够权限的用户无法完成管理 API 调用；前端隐藏菜单只是体验层。

## 界面习惯

| 能力 | 说明 |
| --- | --- |
| 多标签页 | 后台多页签浏览，避免丢上下文 |
| 模块注册表 | 侧栏/页面元数据由注册表驱动，扩展可声明后台入口 |
| 推荐默认 + 恢复 | 可配置项应提供推荐值与一键恢复；恢复若保留密钥会在 UI 说明 |
| Toast | 保存、重置、上传等操作应有成功反馈；错误 Toast 不自动关闭 |

## 用户、角色与权限

| 区域 | 说明 |
| --- | --- |
| 用户列表（`/control-panel/users`） | 搜索与分页、按加入/更新时间/用户名/昵称/邮箱/状态排序、编辑与封禁/解封、查看资料与安全状态 |
| 角色 / 用户组（`/control-panel/roles`） | 角色模板、权限矩阵、成员管理；扩展权限建议可按角色批量授予 |
| 权限（`/control-panel/permissions`） | 权限键目录与授予/撤销；插件可**声明**权限键，但安装/启用**不得**自行赋权，授权始终由宿主角色管理完成 |
| 用户级覆盖 | 单个用户的额外权限/限制，覆盖角色默认值 |

权限以后端策略为权威：隐藏按钮只是体验。新增后台能力时，权限键应可授予，
而不是写死「只有超级管理员」除非安全必需。

## 论坛设置、分类与标签

| 区域 | 说明 |
| --- | --- |
| 论坛设置（Site Settings） | 主题/评论长度、嵌套评论、发布冷却、访客阅读、注册策略、标签策略、搜索、社区守则/隐私/条款链接等 |
| 分类（`/control-panel/forum/categories`） | 分类树、分组、图标与颜色、slug、可见性 |
| 标签 | 标签策略（是否强制、数量上限）、常用标签管理 |
| 内容管理 | 主题/回复筛选与编辑、受限版本时间线查看、历史版本恢复（必须填写原因） |

## 内容审核与举报

- 版务工作台（`/control-panel/moderation`）：举报队列、预审、处理操作
  （隐藏/恢复、锁定、删除等）与审核轨迹。
- 举报由用户发起，站务处理；处理记录进入审计。
- 内容版本权限：`topic.revision.view_any` 与 `post.revision.view_any` 只允许
  查看历史，不授予编辑；恢复还需要 `topic.edit_any` / `post.edit_any`。
- 脱敏历史版本是不可逆的 `super_admin` 操作，当前版本不可脱敏；历史原始
  正文、恢复原因与附件提供方细节不会进入扩展事件或普通审计日志。

## 附件策略与存储

| 区域 | 说明 |
| --- | --- |
| 附件配置（Attachment Configuration） | 基础配置：上传上限、允许类型；压缩配置：图片变体与回填 |
| 附件管理（Attachment Management） | 文件治理、孤儿清理策略、按用户/类型筛选 |
| 存储提供方 | 内置文件系统（`sforum.storage-fs`）与 S3 兼容存储（`sforum.storage-s3`，支持 AWS S3 / MinIO / R2）；可配置多实例、探测与写者选择。S3 插件是受保护内置扩展，多实例根不可选为写者 |

上传资格由现有 RBAC 决定，角色/用户策略可设置单文件大小限制；超出返回 413。

## SMTP、邮件投递与测试

| 区域 | 说明 |
| --- | --- |
| 邮件设置（Mail Settings） | 选择邮件提供方（内置 SMTP `sforum.smtp` 等）、配置主机/端口/加密/发件人、连接探测 |
| 测试邮件 | 发送测试邮件验证配置（测试邮件不计入冷却与频率限制） |
| 投递历史 | 投递记录、失败原因、尝试次数（重试为后台自动） |
| 通知邮件 | 按类型（回复/提及/版务等）设置邮件策略与用户默认偏好 |

## 站点品牌、导航、页脚与公告

| 区域 | 说明 |
| --- | --- |
| 个性化（`/control-panel/personalization`） | 站点名称、Logo、favicon（可上传品牌 SVG，安全栅格化为 PNG）、外观主题色 |
| 站点导航（Site Chrome） | 顶部导航、侧栏、移动导航、页脚导航的配置与排序（多版本修订） |
| 公告 | 公告编写（时间窗口、置顶）与展示管理 |
| 站点设置 | 站点 URL、注册策略、账户安全策略等 |

## SEO

- `/control-panel/seo`：站点级 SEO 配置（元数据、robots、sitemap 相关）。
- 公开页面标题/描述/canonical 由统一的 SEO 解析器生成；插件与主题可扩展
  页面级 SEO 元数据。

## Webhook

- `/control-panel/webhooks`：端点管理、事件订阅与投递记录查看。
- 出站投递由后台任务执行（River 队列），失败按队列策略**后台自动重试**；
  后台页面只展示投递记录（含尝试次数），当前**没有手动重试按钮**。
- 入站 `POST /webhooks/inbound/{source}` 目前只是 gateway skeleton：只校验
  非空 body 并回执，跳过 CSRF；插件 verify/parse hooks 尚未接入。

## 系统更新与后台任务

| 区域 | 说明 |
| --- | --- |
| 系统更新 | 后台发现新版本（检查结果最多缓存 5 分钟，并可手动强制检查）、更新提示与引导；生产更新实际执行走 `upgrade.sh` / `deploy.sh`（见[生产部署](../deployment.md)） |
| 后台任务（`/control-panel/jobs`） | River 队列状态、队列暂停/恢复、任务详情/重试/取消 |
| 调度任务（`/control-panel/schedules`） | 定时任务列表与手动触发 |
| 数据库（`/control-panel/database`） | 只读表检查与元数据（需 `database.manage`） |
