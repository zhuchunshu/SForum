# 产品说明

[← 中文文档首页](./README.md)

## 一句话

SForum 是**开源论坛框架**：给不同社区运营者开箱可用的论坛能力，同时用稳定扩展契约承载部署相关差异（邮件、存储、搜索引擎、支付等）。

## 设计原则

1. **插件优先**：厂商与通道逻辑进扩展；核心保留模型、权限、事件、槽位与默认值。  
2. **新手友好**：推荐默认、清晰文案、一键恢复推荐配置。  
3. **权限感知**：每个写操作有主体、动作、资源；API 权威。  
4. **可维护**：模块边界清晰，避免巨型文件与隐式猴子补丁。  
5. **双语产品**：默认简体中文，并支持 `en-US` 等。  

## 用户与角色

- 单一用户体系  
- 首个注册用户 → 受保护 `super_admin`  
- 后续默认 `member`  
- 角色 + 权限矩阵 + 用户级覆盖  

## 论坛能力（核心）

- 分类 / 标签 / 主题 / 树形评论  
- 编辑窗口、冷却、访客阅读等可运营策略  
- 版主操作与举报 / 预审  
- 附件上传与治理  
- 站内通知 + 邮件投影（传输插件化）  
- SEO 与站点外观 / 导航 / 公告  

## 明确倾向插件化的领域

支付网关、出站邮件传输、通知通道、分析、外部身份、对象存储厂商、可选搜索引擎等。

核心可提供：**意图/流水/权益** 等中性模型与槽位，而不是写死某一厂商。

## 非目标（当前）

- 不是「同进程 PHP 随便 include」式扩展  
- 不把 Kubernetes 多租户云做成默认假设  
- 不把每个社区的业务垂直功能硬编码进核心
