# SForum 后台管理 UI 现代雅致风格升级设计文档 (Design Spec)

本文档定义了 SForum 后台管理 Control Panel 界面进行 UI 现代化改造的技术设计方案。

## 1. 目标与背景 (Goal & Background)

当前 SForum 控制台界面在字号选择、侧边栏排版和内容卡片边框上存在局限，用户反馈后台布局“太小气”、左侧菜单文字“不够显眼/偏小”、内容区域“看起来有点老”。

本方案的目标是根据用户选定的 **方案三：现代雅致 (SaaS 风格)**，对后台 UI 进行整体升级，提供更大气、对比度更高、更具现代感的后台操作体验，且完美兼容浅色和深色主题。

## 2. 关键变更与设计细节 (Key Changes)

### 2.1 全局后台样式 Token 调整 (`main.css`)
*   **侧边栏菜单文字加大与亮化**：
    *   主菜单链接字号提升（如从原来的 `0.875rem` / 14px 调整，并加宽间距），使得排版更显眼。
    *   提升未激活文字的对比度：浅色模式下使用 `#334155` (slate-700)，暗色模式下使用 `#cbd5e1` (slate-300)，确保在弱光或强光环境下均醒目易读。
    *   主菜单的 Hover 与 Active 状态加宽 padding (增加呼吸感)，激活状态背景色和边框更加雅致。
*   **内容卡片与背景设计重构**：
    *   **浅色模式下**：背景设为极淡的灰色，去除呆板的生硬灰色边框，卡片统一采用极淡边框和优雅的环境阴影 (`shadow-[0_8px_30px_rgb(0,0,0,0.015)]`)。
    *   **深色模式下**：背景降为纯粹深色 (`zinc-950`)，卡片采用深灰色 (`zinc-900`) 并赋予微透明边框，去除暗沉老气的感觉。

### 2.2 全局后台布局模板重构 (`admin.vue`)
*   **置顶全局 Topbar 扩容**：
    *   高度从 `54px` 拓宽至 `64px`，带来更大气的留白。
    *   面包屑路径加粗，强化指示作用。
*   **侧边栏指示与底部用户信息升级**：
    *   侧栏底部的管理员信息卡片 (Avatar / Username) 字号加大、排版舒展，并对头像区域增加柔和边缘投影。
    *   嵌套折叠多级菜单左侧的连接引导虚线线宽和颜色微调，使之更加高级隐蔽。
*   **多页签栏 (Tab Bar) 打磨**：
    *   页签栏加高，并微调 active 状态下与下方主内容区的过渡边框，消除错位线。

### 2.3 后台主页及卡片组件升级 (`pages/admin/index.vue`)
*   **核心指标卡片现代化改造**：
    *   数据字号加粗并放大。
    *   为卡片内的 Lucide 图标设计专属的 **彩色半透明毛玻璃背景容器**（例如：绿色图标配绿色背光，蓝色图标配蓝色背光等），使指标数据一目了然且富有现代灵动感。

## 4. 验证与测试方案 (Verification Plan)

### 4.1 自动化测试
*   运行后台框架校验脚本，确保后台基础路由与 tab 机制正常工作：
    ```sh
    bun tests/validate-admin-framework.ts
    ```

### 4.2 手动视觉核对
1.  启动 `apps/web` 本地开发服务器，访问后台控制面板路由。
2.  进入管理后台页面，切换深色/浅色模式，核对：
    *   左侧侧边栏文字在两种模式下是否足够显眼，字号与间距是否舒展大气。
    *   内容区域卡片是否存在老旧边框，阴影是否柔和自然。
    *   多页签切换时，过渡和选中态指示器是否平滑。
    *   仪表盘数据卡片的图标背光效果是否显现且美观。
