## 一、后端：goldmark 启用 GFM 扩展 + 放开 sanitizer（修复表格/删除线/任务列表/链接化）

**文件 `apps/api/app/Models/Forum/renderer.go`**
- import 增加 `"github.com/yuin/goldmark/extension"`。
- 第 38-41 行：把 `goldmark.Convert(...)` 换成实例化带扩展的渲染器：
  ```go
  md := goldmark.New(goldmark.WithExtensions(extension.GFM))
  var buffer bytes.Buffer
  if err := md.Convert([]byte(safeRaw), &buffer); err != nil { ... }
  ```
- `sanitizeHTML`（85-90 行）：在 UGCPolicy 基础上放开两处（预研实测确认后按需）：
  - 保留代码块语言 class：`policy.AllowAttrs("class").Matching(regexp.MustCompile(\`^language-[a-z0-9+#.-]+$\`)).OnElements("code")` —— 让前端 highlight.js 能精确识别语言（实测若 UGCPolicy 已保留则跳过）。
  - 放开任务列表 checkbox：`policy.AllowElements("input")` + `AllowAttrs("type").Matching(^checkbox$)` + 允许 `checked`/`disabled`（TaskList 输出 `<input type="checkbox" checked disabled>`，只读、无 onclick，安全）。
  - import 增加 `"regexp"`（若尚未引入）。

**文件 `apps/api/app/Models/Forum/types.go`**
- 第 16 行 `RenderVersion` 升版本：`"goldmark-bluemonday-v1"` → `"goldmark-bluemonday-v2"`。表示渲染产物格式变化（存量帖保持 v1，编辑后升级 v2）。

**文件 `apps/api/app/Models/Forum/renderer_test.go`**（新增用例，复用现有 `TestRenderXxx` 风格）
- `TestRenderMarkdownRendersGFM`：断言表格 → `<table>`/`<th>`、删除线 → `<del>`、裸链接 → `<a href>`、任务列表 → `<input type="checkbox"`、代码块带 `class="language-go"`。
- 补一个 sanitizer 安全断言：`<input type="text">`、`<input onx=...>` 等非 checkbox input 仍被 strip（验证放开是收敛的）。
- 运行 `./scripts/test.sh`（或 `go test ./app/Models/Forum/`）确认全绿。

> 不新增迁移、不写批量重渲染脚本。存量帖的 html_content 在下次编辑时由 service.go 既有逻辑自然更新为 v2。会在知识库 decision 里记录此取舍。
