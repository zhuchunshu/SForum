# SForum UI 重设计 — Demo C 百分百还原实施计划

## 铁律约束（不可违反）

以下约束逐条钉死，任何偏离都视为 bug：

### 约束 1：唯一视觉基准
- **唯一基准**：`/tmp/sforum-demos/demo-c.html`。所有布局、间距、字号、颜色、DOM 结构以此文件为准。
- 实施时逐屏对照 `demo-c-{light,dark}-hero.png` 截图验收。亮/暗双模式都必须对齐。
- **禁止"灵感式发挥"**：不自行调整间距、字号、圆角、阴影。原型 `border-radius:8px` 就 8px，原型 `gap:.75rem` 就 `.75rem`。

### 约束 2：数据真实性（不显示假数据）
Demo C 原型有几处数据 API 不提供，按以下**确定规则**处理（已与你逐条确认）：

| 原型元素 | 处理方式 | 理由 |
|---|---|---|
| 评论操作行 👍按钮+数字 | **保留按钮，删除数字** | API 无 likeCount，不显示假数 |
| 帖子右侧统计卡"点赞"行 | **整行删除** | 同上 |
| 作者卡"428主题·1.2k回复"子统计 | **删除，只留头像+名字** | API 无作者发帖统计 |
| 首页列表行 | **无点赞列**（原型本就没有） | — |

除以上 4 处明确删减外，**其余元素 1:1 还原**。

### 约束 3：不动后端/契约/数据库
- 不改 `apps/api/` 任何 Go 代码
- 不改 `contracts/openapi/` 任何文件
- 不加 DB migration
- 不新增 API 字段（likeCount/role/participants 全不做）

### 约束 4：只用现有 token 与组件
- 颜色全用 `--sf-*` token（`--sf-accent` / `--sf-fg` / `--sf-card` / `--sf-border` / `--sf-muted` / `--sf-violet` / `--sf-success` 等，已在 sforum-components.css 定义）
- 复用现有组件：`SFCard` / `SFBadge` / `SFAvatar` / `SFEmptyState` / `SFSkeleton` / `SFPagination` / `SFAlert` / `SFButton` / `SFSearch`
- 图标只用 `i-lucide-*`（现有用法），不引新图标包
- 新增的 violet 徽章用现有 `--sf-violet` token（已定义）

### 约束 5：OP 徽章实现方式
- 触发条件：`comment.authorUserId === topic.value?.authorUserId`（在详情页计算）
- 通过新增 `commentBadgesBuilder?: (comment) => Badge[]` 传给 SFComment（复用现有 `commentActionsBuilder` 模式）
- 不做版主/管理员徽章（API 不返回评论者角色，已确认）

### 约束 6：i18n 双语同步
- 改 zh-CN.json 必须同步改 en-US.json，key 路径完全一致
- 新增 key 最小化（见下文清单）

## Demo C 精确规格（从原型提取，作为验收标准）

### 首页（demo-c.html L67-130, L233-400）
- **grid**：`200px minmax(0,1fr) 290px`（三栏），gap `1rem`
- **左栏** `.cat-rail`：sticky top:68px。按钮 `height:32px`，active 态 `background:var(--sf-accent-soft);color:var(--sf-accent)`
- **列表行 grid**（L74,77）：`grid-template-columns:minmax(0,1fr) 60px 70px 130px`，即 **主题 | 回复(60px) | 浏览(70px) | 活动(130px)**
- **表头**：`font-size:.72rem;font-weight:700;text-transform:uppercase;letter-spacing:.03em;color:var(--sf-fg-tertiary);background:var(--sf-muted)`，列2-4右对齐
- **行结构**：作者头像(40px圆) + 标题行(置顶/锁定图标 inline) + meta(分类带色点+标签+作者名) | 回复数(mono) | 浏览数(mono) | 头像栈+活动时间
- **行 hover**：`background:var(--sf-accent-soft)`
- **右栏** `.right`：sticky，两个 panel：
  - 统计面板：标题"社区统计"+图标，4 行 stats-row（主题/回复/用户/在线），数值 mono 右对齐。**注意：用现有数据 `totalCategoryThreads`/`totalCategoryComments`；用户数/在线数 API 无 → 这两行也按"不显示假数据"删除，只保留主题+回复两行**
  - 热门标签面板：遍历 `activeTags`，`#name` + `topicCount mono`

### 帖子页（demo-c.html L131-165, L401-505）
- **grid**：`minmax(0,1fr) 290px`（两栏，无 action-rail）
- **topic-card**：`border-radius:10px;padding:1.5rem`。面包屑 → badge 行 → 标题(1.75rem/800) → byline(头像36px+名字+meta图标行) → prose → tags → actions
- **右侧 topic-side**：sticky，两个 panel：
  - 主题信息：浏览/回复/创建（**删点赞行**）
  - 作者：头像40px+名字（**删"N主题·N回复"**）

### 评论（demo-c.html L166-200, L450-505）
- **cmt grid**：`36px minmax(0,1fr)`，gap `.75rem`，padding `1rem 1.25rem`
- **head**：名字(700/.84rem) + 角色徽章(OP=violet) + 时间(.72rem/tertiary)
- **OP 徽章** `.cmt__role--op`：`background:var(--sf-violet);color:#fff;font-size:.6rem;font-weight:700;padding:.1rem .35rem;border-radius:3px;text-transform:uppercase`
- **操作行**：👍按钮(无数字) + 回复 + ⋯ 。按钮 `height:26px;font-size:.73rem`，hover `background:var(--sf-muted);color:var(--sf-accent)`
- **引用块** `.cmt__quote`：左 3px accent 边 + soft 底 + `corner-up-left` 图标，author accent 色 + 文本省略
