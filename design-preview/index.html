SForum 样式方案 预览与选择

针对首页和帖子内容页，参考 linux.do 与 discuss.flarum.org，制作了 3 套差异化方案。
所有方案都复用了 SForum 现有的设计 token（teal #0f766e 主色、Inter + Noto Sans SC 字体、8/12px 圆角），可直接融入现有主题层。

参考站点： linux.do · discuss.flarum.org
方案 A

Discourse 密集表格风

参考：linux.do

信息密度最高的方案。话题按分类分组，每行包含头像、标题、标签、回复数、浏览数、最后回复者。三栏布局带左侧分类导航。

  • 分类分区，适合话题量大、分类清晰
  • 表格化列：回复 / 浏览 / 最后活动
  • 帖子页楼层式，带楼层编号
  • 左右双栏，信息触达效率最高

方案 B

Flarum 极简轻量风

参考：discuss.flarum.org

最干净轻量的方案。窄列居中（760px），大量留白，回复数做成独立的圆角气泡。无边框分隔，靠留白和轻阴影区分。

  • 单栏窄列，阅读体验最纯粹
  • 回复数气泡，Flarum 招牌设计
  • 帖子页紧凑回复卡，轻盈
  • 视觉噪音最少，适合内容驱动

方案 C

现代卡片流风

参考：Linear / Notion 社区

介于 A 和 B 之间的现代方案。卡片化展示，每张卡片含投票块、标题、两行摘要、标签、浏览数。首页带 Hero 统计带，帖子页带右侧目录。

  • 卡片悬浮动效，交互感强
  • 投票/点赞块前置，社区氛围浓
  • 帖子页大标题 + 目录侧栏
  • 视觉层次最丰富，最"现代感"

三方案对比
维度 A · Discourse 表格 B · Flarum 极简 C · 现代卡片流
信息密度 最高 最低 中等
阅读舒适度 中 最高 高
视觉现代感 偏传统论坛 极简轻量 最现代
分类浏览 分类分区强 标签筛选 标签 + 筛选
适合场景 大社区、技术深、话题多 小社区、重讨论、轻阅读 产品社区、综合型
布局栏数 三栏（导航+列表+侧栏） 单栏居中 双栏（列表+侧栏）
帖子页风格 楼层式 + 点赞列 紧凑回复卡 大标题 + 目录 + 嵌套回复
改动工作量 中（重写首页+topic） 小（列表项简化） 中（新增卡片组件）
说明：三个方案的 HTML/CSS 都是独立可运行的静态 demo，没有依赖项目运行环境。 所有配色、字体、圆角都复用了 SForum 现有 token，确认方案后我可以直接迁移到主题层 （extensions/builtin/themes/sforum-default/layer/ 下的 index.vue、t/[...path].vue 及对应 CSS）。 你也可以混搭，比如「首页用 A、帖子页用 C」——告诉我你的偏好即可。
