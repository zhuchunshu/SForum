# 2026-10-23 发布 v3.0.13-alpha.2（已发布）

## Changed

- **发布前修掉两个红灯**（都在发布 commit 之前进 main）：
  - `18d99c82a fix(identity)`：`PostgresStore.ReplaceRolePermissions` 现在在同一事务内
    先对 `roles` 行取 `FOR NO KEY UPDATE`，与 IdentityRegistry 插件权限审批共享同一个
    串行化根。此前替换是裸 `DELETE` + `INSERT`，并发审批会把它顶成
    `role_permissions_pkey` 23505（2026-10-22 main CI 的 Go gate 失败）。新增
    `postgres_store_roles_lock_integration_test.go` 用「持锁 + 500ms 窗口」钉住不变量：
    去掉锁，新测试立刻失败。
  - `e1656526e test(homepage)`：`d333f0060` 移除了信息流页码控件，但仓库级静态契约
    `tests/validate-homepage.js` 仍要求 `<SFPagination>`/`publicPageLocation`，
    contracts job 直接红。改为反向断言：页码 token 不得回到 feed 岛，底部状态区必须
    保留 `aria-live`。
- **发布结果**（run 39876943347，24 个 job 全 success）：
  - `ghcr.io/zhuchunshu/sforum-{api,migrate,web}:3.0.13-alpha.2`（linux/amd64 +
    linux/arm64，带 build provenance attestation），匿名拉取校验通过。
  - GitHub Pre-release：4 个 CLI 资产 + 2 个 server 资产 + `sforum-bootstrap.sh` +
    `upgrade.sh` + `sforum-deploy.tar.gz` + `SHA256SUMS`。
  - 发布镜像冒烟（迁移 / 健康检查 / worker 心跳）与阻断式 trivy 扫描均通过。
  - npm `@sforum/{admin-sdk,plugin-ui}@1.1.0` 命中 exact-artifact，按设计跳过发布。

## Decisions

- 版本沿用当前 patch 线（`3.0.13-alpha.2`）而不是新开 `3.0.14`：自 `v3.0.13-alpha.1`
  起 17 个提交里没有跨 patch 线的破坏性变更，属于同一功能批次的迭代。
- 发布说明用 `**粗体**` 分节而不是 `#` 标题：`git tag -a -m` 的默认 cleanup 会吃掉
  `#` 开头行（实测确认），`release.sh` 走 `-m`，所以 tag annotation 里不能放 Markdown
  标题。
- 信息流移除页码后的静态契约改为「禁止回归」写法，与
  `knowledge/decisions/2026-10-23-public-feed-loading-model.md` 和 web 单测对齐。
