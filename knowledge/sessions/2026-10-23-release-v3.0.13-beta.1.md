## Decisions

- alpha.2 → beta.1：`57a01e375` 是 v3.0.13 功能批次的收尾特性（内置插件自动
  更新），按通道语义进 beta；未新开 patch 线。
- 本轮「全绿」只覆盖 main 的 CI + Security + Release tooling；Dependabot
  （nuxt 4.6.2 / `@nuxt/ui` 4.12 / `@nuxtjs/seo` 6 / golang 1.27.2 基础镜像）
  仍单独一轮。
- 预发布不移动 `latest`：promote 只在 `STABLE=true` 时追加 `major_minor` 与
  `latest` 标签；本次只写版本标签。
