# 2026-08-01 V3 Stable Release

## Changed

- Prepared `v3.0.1` as the first published stable SForum V3 release after the alpha.13
  CI, Security, multi-architecture image, asset, and production rollout gates.
- Fresh `deploy.sh` installations now resolve `latest` through GitHub's latest
  stable Release and persist only the resulting immutable version.
- The Chinese and English deployment guides now provide clone-free archive
  installation and updater refresh commands.

## Decisions

- `v3.0.0` failed its exact-main CI before image publication because the new
  update prompt lacked a reviewed V3 UI identity. The public tag remains
  immutable; the catalog fix and first published stable release use `v3.0.1`.
- Linux `amd64` and `arm64` are the supported production platforms. Windows is
  not supported.
- Database migrations continue to use the maintenance-window deploy path;
  migration-free updates may use the blue/green updater.
