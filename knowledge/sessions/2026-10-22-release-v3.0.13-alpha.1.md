# 2026-10-22 发布 v3.0.13-alpha.1（已发布）

## 版本决策

- 上一个 tag `v3.0.12-alpha.6`（10-14）之后 main 累积 69 个提交、多个可感知功能，
  按历史上 `3.0.11 → 3.0.12` 的切换方式开新 patch 线：**`v3.0.13-alpha.1`**。
- tag annotation 用结构化发布说明（`--cleanup=verbatim`；`git tag -F` 默认会吃掉
  `#` 开头的行，第一次创建时 markdown 标题全被删掉，已修正）。

## 发布过程中发现并修掉的三处真实缺陷

1. **Go stdlib CVE-2026-111943**（HIGH，crypto/x509 接受不可信中间证书，
   fixed 1.26.10 / 1.27.3）。发布侧镜像是**阻断式**扫描（`exit-code: "1"`），
   所有由 `apps/api` 构建的镜像都带 1.26.9 → migrate 候选首次即失败。
   CI 的容器扫描是 report-only，所以这个问题只在打 tag 时暴露（#183）。
   - 只改 anchor 会连带打断容器构建：插件模块 `require` 主模块（replace），
     依赖的 go directive 更高时 Go 在 `-mod=readonly` 下拒绝构建
     （`updates to go.mod needed`）。因此 26 个 tracked `go.mod` 一并同步。
2. **migrate 缺绝对 `EXTENSION_ROOT`**：`config.Load` 自 10-16 起在生产态
   fail-closed 拒绝相对路径，而 `compose.prod.yaml` 的 migrate 服务从未传该变量
   （api 有）。发布冒烟在 migrate 步骤 panic。已在 compose 补默认值，并在
   `compose-production_test.sh` 加"必须存在且以 `/` 开头"的断言（#184）。
3. **内置插件源码契约漂移**：#183 改了 8 个插件 `backend/go.mod`，而
   `release-tooling.yml` 的触发 paths 不含 `go.mod`，所以 PR 阶段没暴露；
   #184 碰到 `deploy/**` 才把它顶出来。按契约 bump 8 个插件的 patch 版本并
   `--write` 刷新 baseline（auth-github 1.0.8、content-policy 1.1.7、
   search-site 1.0.7、shortcodes 1.3.5、smtp 1.1.7、storage-fs 1.1.8、
   storage-s3 1.0.9、web-push 1.0.7）。

## 第四个阻塞点：npm Trusted Publishing 从未被真正验证

- 前两次 release 都停在 `Publish versioned Web SDKs`，`npm publish
  @sforum/admin-sdk@1.1.0` 返回 `E404 404 Not Found - PUT ...`。
- provenance 已成功签名，说明 OIDC 交换正常，问题在包侧授权。
- 根因：npm 上两个包此前只有 `1.0.0`，v3.0.12-alpha.6 那次是
  `already contains the exact SDK content` **直接 skip**，所以 Trusted Publisher
  从未生效过；本次 SDK 升到 `1.1.0` 是第一次真实 publish。
- 处置：operator 在 npm 上为 `@sforum/admin-sdk`、`@sforum/plugin-ui` 配置
  GitHub Actions trusted publisher（repo `zhuchunshu/SForum`，workflow
  `release.yml`，allow publish），随后 `gh run rerun --failed` 只重跑 SDK 发布
  与其后继 job，省掉整轮重建。

## 最终结果（run 39824505114 → re-run 后 success）

- 24 个 job 全 success：prepare、verify main CI、6 个平台候选镜像构建 + 阻断式扫描、
  3 个 manifest merge、发布镜像冒烟（迁移 / 健康检查 / worker 心跳）、
  4 个平台 release asset、asset 校验、SDK 发布、3 个镜像 promote、
  匿名拉取校验、GitHub Release 创建。
- 产物：`ghcr.io/zhuchunshu/sforum-{api,migrate,web}:3.0.13-alpha.1`（linux/amd64
  + linux/arm64，带 attestation）；GitHub Pre-release + 10 个资产（4 个 CLI、
  2 个 server、`sforum-bootstrap.sh`、`upgrade.sh`、`sforum-deploy.tar.gz`、
  `SHA256SUMS`）；npm `@sforum/admin-sdk@1.1.0` 与 `@sforum/plugin-ui@1.1.0`
  的 `latest` 均已指向 1.1.0。
- 发布说明来自 tag annotation 的结构化分节（脚本只在前面加了一行项目 tagline）。
