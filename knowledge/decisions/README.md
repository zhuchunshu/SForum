# Decisions

Decision records live here.

Use one file per meaningful decision:

```text
YYYY-MM-DD-short-title.md
```

Suggested format:

```md
# Decision: Title

## Status

Proposed | Accepted | Replaced

## Context

Why this decision is needed.

## Decision

What was chosen.

## Consequences

Tradeoffs, risks, and follow-up work.
```
